# PHP2SHELL

### Explore PHP. Intract with Linux. Understand Web Security.

PHP2SHELL is an educational cybersecurity project demonstrating how PHP intracts with the Linux operating system throught a web interface.

Built for developers, Linux enthusiasts, and cybersecurity learners who want to explore PHP command execution and understand the security risks of web shells.

--- 

## Features

- Simple PHP web interface
- Linux system information
- PHP environment information
- Edicational command-execution demonstrations
- Localhost-only access
- Lightweight and easy to set up

## Requirements

- Linux operating system
- PHP 8.0 or newer
- A modern web browser
- Basic knowledge of PHP and Linux

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/N3ONSH/php2shell.git
```

### 2. Enter the project directory

```bash
cd PHP2SHELL
```

### 3. Start the local PHP server

```bash
php -S 127.0.0.1:8000
```

### 4. Open PHP2SHELL

Visit: http://127.0.0.1:8000

---

## Security Disclaimer

PHP2SHELL is intended exclusively for educational puposes and authorized local security testing.

The public educational version users restricted diagnostic operations rather than unrestricted operating-system command execution.

Never expose an unretricted PHP web shell to the public internet or use it on systems  without explicit authorization.
